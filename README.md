# itiseasy

Консольная утилита на Python для измерения скорости скачивания данных по HTTP/HTTPS.

Программа выполняет последовательные запросы к указанному URL, дожидается полного скачивания каждого ответа, измеряет время загрузки и рассчитывает статистику.

## Возможности

- Последовательное выполнение HTTP/HTTPS-запросов.
- Настраиваемое количество запросов (по умолчанию — 10).
- Потоковое скачивание данных с использованием `requests`.
- Отображение текущей скорости скачивания во время загрузки.
- Измерение времени каждого запроса.
- Подсчёт общего объёма скачанных данных.
- Расчёт среднего времени запроса и средней скорости скачивания.
- Обработка ошибок отдельных запросов без остановки остальных.
- Настраиваемые таймауты подключения и чтения.
- Корректное закрытие HTTP-сессии и обработка прерывания программы.

## Технологии

- Python 3.10+
- Requests

## Установка

Клонируйте репозиторий:

```bash
git clone https://github.com/Desorr/itiseasy.git
cd itiseasy
```

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его.

macOS / Linux:

```bash
source venv/bin/activate
```

Windows:

```bash
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

Базовый запуск:

```bash
python main.py https://example.com/image.jpg
```

По умолчанию программа выполняет 10 последовательных запросов.

### Параметры

| Параметр | По умолчанию | Описание |
|---|---:|---|
| `url` | — | URL для скачивания |
| `--count` | 10 | Количество запросов |
| `--connect-timeout` | 10 | Таймаут подключения (сек.) |
| `--read-timeout` | 60 | Таймаут чтения (сек.) |
| `--chunk-size` | 64 | Размер блока скачивания (KB) |

### Примеры

Выполнить 5 запросов:

```bash
python main.py https://example.com/image.jpg --count 5
```

Изменить таймауты:

```bash
python main.py https://example.com/image.jpg --connect-timeout 5 --read-timeout 30
```

Изменить размер блока скачивания:

```bash
python main.py https://example.com/image.jpg --chunk-size 128
```

Посмотреть все доступные параметры:

```bash
python main.py --help
```

## Единицы измерения

## **Единицы измерения**

Для отображения результатов используется десятичная система измерения:

- 1 KB = 1 000 bytes;
- 1 MB = 1 000 000 bytes;
- 1 GB = 1 000 000 000 bytes.

В программе используются следующие единицы:

- Размер блока скачивания (`--chunk-size`) — KB.
- Объём скачанных данных — MB.
- Время загрузки — секунды (сек.).
- Текущая и средняя скорость скачивания — MB/s (мегабайт в секунду).

## Расчёт статистики

После завершения выполнения программа выводит:

- Количество успешных запросов.
- Количество неудачных запросов.
- Общий объём скачанных данных.
- Суммарное время скачивания.
- Среднее время одного успешного запроса.
- Среднюю скорость скачивания.

Средняя скорость рассчитывается как отношение общего объёма успешно скачанных данных к суммарному времени успешных загрузок.

## Обработка ошибок

Если отдельный запрос завершается ошибкой, программа выводит сообщение об ошибке и переходит к следующему запросу.

Если все запросы завершились неудачно, программа сообщает об этом и возвращает соответствующий код завершения.

Прерывание выполнения через `Ctrl+C` также обрабатывается корректно.
